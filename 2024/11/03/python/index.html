成员运算符:检查字符串中是否包含了某个子字符串

3.字符串常见操作

1.下标/索引

python中下标从左往右0开始

作用：通过下标快速能够找到对应的数据

格式：字符串名[下标值]

python中下标从右往左-1开始

2.切片

含义：指对操作对象截取其中一部分的操作。

语法：[开始位置:结束位置:步长]

包前不包后（左闭右开）

步长的绝对值大小决定切取的间隔，默认为1.正负号决定切取方向。

3.查找
1.Find()

:检测某个子字符串是否包含在字符串中，如果在就返回该字符串开始位置的下标(索引值)，否则就返回-1

2.index()

:检测某个子字符串是否包含在字符串中，如果在就返回该字符串开始位置的下标(索引值)，否则就报错

3.count()

：返回某个子字符串在整个字符串的中出现的次数，没有则返回0

包前不包后

4.判断
1.startswith()

：是否以某个字符串开头，是则返回true，否则false

2.endswith()

: 是否以某个字符串结束，是则返回true，否则false

3.isupper()

: 检测字符串中所有字母是否全为大写，是则返回true,否则false

5.修改元素
